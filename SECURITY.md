# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue:
use **[Report a vulnerability](https://github.com/alecvs3/MossDL/security/advisories/new)** on GitHub.

Include what you found, how to reproduce it, and the MossDL version you are running. You'll get an answer
within a week, and a fix or a plan soon after. Credit is given in the release notes unless you'd rather not be named.

## What counts

Anything that lets a web page, a file host, a plugin or another program on the machine do something the user didn't
ask for. For example:
- reading or sending the user's cookies, keys or credentials;
- sending traffic outside the connection the user chose;
- writing files outside the chosen download folder (including through archives);
- running code through the browser extension or the engine's local interfaces.

## Supported versions

Only the latest release gets security fixes.
